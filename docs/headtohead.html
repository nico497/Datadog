How this works, and what it doesn't cover yet

  • Forced-pick question: "If you had to pick one observability and monitoring platform for an engineering team, Datadog or {rival}?" Asked in both name orders, 5 fresh runs each (60 answers total), via the OpenAI API (gpt-4o) directly — no browsing, no memory, no personalization.
  • Open comparison question: "Datadog vs. {rival}: which should I choose?" Asked once per order (12 answers) — this is where the qualitative reasoning below comes from. It is not repeated, so a single odd answer could be noise, and since it's the API with no browsing, there are no citations to check — just the model's general knowledge of each product.
  • Both orders are asked because the model can lean toward whichever brand is named first. For New Relic, Splunk and Elastic Observability it doesn't matter — Datadog sweeps 10 of 10 either way. Grafana Labs and Sumo Logic are near-sweeps (9 of 10) with a mild order lean. Dynatrace is the one genuine contest: Datadog sweeps when named first, but Dynatrace wins the majority when named first instead — a real order-sensitive split, not a lopsided win for either side.
  • Not yet covered: pricing, integrations, deployment model and support as separate scored dimensions — they'd need their own repeated, structured prompts to be real rather than invented. Also not covered: any engine besides this one, and any run with browsing or a logged-in session.
